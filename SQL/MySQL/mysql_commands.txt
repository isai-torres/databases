Important: Some commands are specific to Arch Linux, but most should work on other operating systems too.

I. MySQL basic Terminal Commands:

  1. sudo mysql --> runs MySQL as a root user.

  2. mysql -u user -p --> runs MySQL with a specific user (-u) and password (-p). mysql -u user -p database_name --> connects to a specific database.

  3. GRANT ALL PRIVILEGES ON database_name.* TO 'username'@'localhost'; --> This command grants all privileges on a specific database to a user. You can replace database_name.* with *.* to grant privileges on all databases (global privileges). You can also specify in which table for example: GRANT ALL PRIVILEGES ON database_name.table_name TO 'user_name'@'localhost'; (.* means to all tables).

  4. GRANT ALL PRIVILEGES ON *.* TO 'username'@'localhost' WITH GRANT OPTION; --> The "WITH GRANT OPTION" clause allows that user to grant the same privileges to other users.

  You can also specify which privileges you want to grant. For example:
  GRANT SELECT, INSERT ON database_name.* TO 'username'@'localhost';

  | Privilege      | Description                                    |
  | -------------- | ---------------------------------------------- |
  |  SELECT        | Read data from tables                          |
  |  INSERT        | Add new rows                                   |
  |  UPDATE        | Modify existing data                           |
  |  DELETE        | Remove rows                                    |
  |  CREATE        | Create new tables or databases                 |
  |  DROP          | Delete tables or databases                     |
  |  ALTER         | Modify table structure                         |
  |  INDEX         | Create or remove indexes                       |
  |  GRANT OPTION  | Allow user to grant their privileges to others |

  5. SHOW DATABASES; --> Show all databases.

  6. CREATE DATABASE database_name; --> This command creates a new database.

  7. USE database_name; --> This command selects a database to use.

  8. DROP DATABASE database_name; --> Delete a database.

  9. SHOW TABLES; --> Shows all tables.

  10. DROP TABLE table_name; --> Delete a table.

  11. DESCRIBE table_name; --> Describe a table (see columns).

  12. SELECT user, host FROM mysql.user; --> Shows all MySQL users and the host from which each user is allowed to connect.

  13. Exit; --> Exits MySQL and returns to the system terminal.

II. Check MySQL status and more:

  1. sudo systemctl status mysqld --> This checks if MySQl server is running or not.

  2. sudo systemctl start mysqld --> If not running, start it.

  3. sudo systemctl stop mysqld --> Stops MySQL.

  4. sudo systemctl enable mysqld --> Enable MySQL to start at boot.

  5. sudo systemctl disable mysqld --> Disable MySQL from starting at boot.

  6. sudo systemctl restart mysqld --> Restart MySQL.

III. Users:

  1. CREATE USER 'username'@'localhost' IDENTIFIED BY 'your_password'; --> This command creates a new user. 'localhost' is the address of your server — in this case, it refers to your local machine, but it can also be replaced with a remote address.

  2. DROP USER 'username'@'localhost'; --> Delete an user.

  3. ALTER USER 'username'@'localhost' IDENTIFIED BY 'new_password'; -->  Change a user's password.

  4. RENAME USER 'old_username'@'localhost' TO 'new_username'@'localhost'; --> Rename a user.

  5. RENAME USER 'username'@'localhost' TO 'username'@'%'; --> Change the host a user can connect from, '%' means "from any host" — only do this if you actually need remote access.

  6. REVOKE INSERT, UPDATE ON database_name.* FROM 'username'@'localhost'; --> Revoke privileges.

  7. ALTER USER 'username'@'localhost' ACCOUNT LOCK;
     ALTER USER 'username'@'localhost' ACCOUNT UNLOCK; --> Lock/unlock an account (disable login without deleting it).

  8. SELECT User, Host FROM mysql.user; --> To see current users and their host.

  9. SHOW GRANTS FOR 'username'@'localhost'; --> To see a specific user's privileges.
